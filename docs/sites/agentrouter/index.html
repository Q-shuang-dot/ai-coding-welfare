常见问题

AgentRouter 注册完为什么看不到额度？

公益站额度多在登录时结算，退出登录再重新登录一次通常就到账；余额短暂显示 $0 属于前端展示问题，稍后刷新即可。

AgentRouter 的 Claude Code 报 401 怎么办？

Anthropic 协议的 Base URL 不要带 /v1；再确认 Key 复制完整、模型名在站内可用清单里、客户端属于该站支持的类型。

从别的链接注册 AgentRouter 有区别吗？

有。邀请额度 $50 是在注册那一刻结算的，走裸链拿不到，事后也补不上。
